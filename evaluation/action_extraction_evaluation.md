# Action-Item Extraction & Addressee Tagging Benchmark

**Benchmark Dataset:** EPA Dataset (`EPADataset.tsv`, Microsoft Research / EMNLP W-NUT)  
**Evaluated Samples:** 300 annotated task sentences  

## Performance Metrics

| Metric | Score | Notes |
| :--- | :---: | :--- |
| **Precision** | **0.9333** | Proportion of extracted action items that match ground-truth intent |
| **Recall** | **0.9466** | Proportion of actual task sentences successfully identified |
| **F1-Score** | **0.9399** | Harmonic mean of task extraction precision and recall |
| **Addressee Accuracy** | **0.7419** | Correct assignment of the responsible individual |
